O que é?

Framework front-end open-source de HTML, CSS e JS para sites responsivos e mobile-first.

Mobile-first

Projetado primeiro para celulares; classes como .col-md-* só ativam em telas maiores.

CDN vs Download

Use via CDN (2 linhas de link) ou baixe o CSS/JS. Sem instalação.

Breakpoints

sm:576 · md:768 · lg:992 · xl:1200 · xxl:1400 pixels. Define quando o layout muda.

Grid de 12

Divida a linha em até 12 colunas. .col-6 = metade, .col-4 = um terço.

Componentes

Navbar, cards, botões, alertas, modais, carrossel, accordion, formulários...

Utilitários

Classes prontas: .mt-3 (margin), .text-center, .bg-primary, .d-flex... sem escrever CSS.

Produtividade

Menos CSS escrito, layout consistente, responsividade garantida, manutenção fácil.

Exemplos — Containers

Contêineres são o bloco básico do Bootstrap. Apenas aplicando classes, sem escrever CSS.

1 .container — fixo responsivo

Largura máxima que muda em cada breakpoint, sempre centralizado.

Código:
<div class="container">
  <h1>Meu conteúdo</h1>
  <p>Centralizado e com largura máxima.</p>
</div>
Abrir exemplo completo
2 .container-fluid — 100% largura

Ocupa a tela inteira em qualquer tamanho. Ideal para faixas coloridas.

Código:
<div class="container-fluid bg-primary text-white py-4">
  Faixa colorida de ponta a ponta
</div>
Isto é um container-fluid (100% da largura do box)
3 .container-md — responsivo por breakpoint

100% até 768px; acima disso, largura fixa. Variantes: sm, md, lg, xl, xxl.

Código:
<!-- fluido no celular, fixo no desktop -->
<div class="container-md">
  Conteúdo de leitura
</div>
4 Estrutura padrão de página

Todo site Bootstrap começa assim — 2 linhas de CDN + um container.

Código:
<!doctype html>
<html><head>
  <link href="...bootstrap.min.css" rel="stylesheet">
</head><body>
  <div class="container">
    <h1>Olá, Bootstrap!</h1>
  </div>
  <script src="...bootstrap.bundle.min.js"></script>
</body></html>

Exemplos — Barras de Navegação

Navbar responsiva com botão hambúrguer — apenas classes, zero CSS personalizado.

Código da navbar (funcional, com dropdown e busca):
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="#">Logo</a>
    <button class="navbar-toggler" data-bs-toggle="collapse"
            data-bs-target="#menu">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="menu">
      <ul class="navbar-nav me-auto">
        <li class="nav-item">
          <a class="nav-link active" href="#">Início</a>
        </li>
        <li class="nav-item">
          <a class="nav-link" href="#">Sobre</a>
        </li>
      </ul>
    </div>
  </div>
</nav>
